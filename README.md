# Приложение для выгрузки вакансий определенных работодателей по запросу пользователя

## Цель проекта: 
Проект дает возможность выгрузить:
+ Количество вакансий у каждой из выбранных компаний
+ Список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию
+ Среднюю зарплату по вакансиям
+ Список вакансий с зарплатой выше средней
+ Список всех вакансий, отфильтрованных по запрошенному слову

## Установка:

## Реализованные функции и примеры их работы:
1. Модуль ```hh_api_request```:
 -  Класс ```HeadHunterAPI``` . Для инициализации класса необходимо передать url, по умолчанию url = "https://api.hh.ru"
Методы класса:
 - ```get_employer_id_by_name() ``` Метод принимает на вход строку с названием компании-работодателя. Возвращает id работодателя на hh.ru
 - ```get_employer_info_by_id()``` Метод принимает на вход id работодателя и возвращает в виде словаря его название, id на hh.ru,
ссылку на сайт, ссылку на вакансии и ссылку на описание компании на hh.ru
 - ```get_employer_vacancies()``` Метод возвращает вакансии по запрошенному работодателю 
 - ```fetch_vacancies_for_employers()``` Метод получает на вход список работодателей и возвращает все вакансии этих работодателей
 - ```fetch_info_for_employers()``` Метод получает на вход список работодателей и возвращает описание этих работодателей
2. Модуль ```create_db```:
-  Класс ```CreateDB``` . Для инициализации класса необходимо передать название базы данных и параметры для подключения
Методы класса:
 - ```create_database() ``` Метод создает базу данных с переданным в класс названием
 - ```create_tables_in_the_database()``` Метод создает 2 таблицы в базе данных: вакансии и компании
 - ```save_companies_in_tables()``` Метод сохраняет полученные по api описания компаний в базу данных, на вход принимает
список с описанием работодателей, возвращает словарь с id компаний (name: id)
 - ```save_vacancies_in_tables()``` Метод сохраняет полученные по api вакансии в базу данных, привязывая к id компании,
на вход принимает список с вакансиями всех работодателей
3. Модуль ```db_manager```:
-  Класс ```DBManager``` . Для инициализации класса необходимо передать название базы данных и параметры для подключения
Методы класса:
 - ```get_companies_and_vacancies_count() ``` Метод для получения списка всех компаний и количества вакансий у каждой компании
 - ```get_all_vacancies()``` Метод для получения списка всех вакансий с указанием названия компании, названия вакансии, зарплаты и ссылки на вакансию
 - ```get_avg_salary()``` Метод для получения средней зарплаты по вакансиям
 - ```get_vacancies_with_higher_salary()``` Метод для получения списка всех вакансий, у которых зарплата выше средней по всем вакансиям
 - ```get_vacancies_with_keyword()``` Метод для получения списка всех вакансий, в названии которых содержатся переданные в метод слова. На вход передается строка со словами для поиска
4. Модуль ```utils```:
- ```type_of_salary``` Функция принимает на вход описание вакансии и возвращает зарплату
- ```metro_description``` Функция принимает на вход описание вакансии и возвращает станцию метро или "Метро не указано/В этом городе метро нет"
- ```city_description``` Функция принимает на вход описание вакансии и возвращает город или "Город не указан"
- ```address_description``` Функция принимает на вход описание вакансии и возвращает адрес или "Адрес не указан"
